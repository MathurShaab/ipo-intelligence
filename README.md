# IPO Intelligence — Indian IPO Research & Analysis Platform

A modular, API-ready Indian primary market research and analytics web application built with **HTML5, CSS3, Vanilla JavaScript, Bootstrap 5, Bootstrap Icons, and Chart.js**.

## Current Build Status: Phases 1 & 2 Complete
- **Phase 1 (UI & Design System):** Dark navy/charcoal institutional fintech UI (`assets/css/theme.css`), responsive collapsible sidebar, reusable KPI cards, skeleton loaders, empty/error states, and badge system.
- **Phase 2 (Demo Data & Functional Dashboard):** 14 clearly labeled illustrative Indian IPO records (`assets/js/data/demo-ipos.js`), decoupled `DataProvider` & `IPOService` architecture, KPI summary cards, Market Overview & Subscription charts, Upcoming IPO Calendar, Recent Listing Performance table, and multi-filter IPO Screener (Mainboard, SME, Upcoming, Open, Closed, Listed).

## Disclaimer
All IPO records, subscription multipliers, financial metrics, and Grey Market Premium (GMP) figures in this build are **illustrative demo data** only.
